# 📒 本地会计分录关账台

一个纯前端的本地会计关账练习台：按账期、科目和来源凭证管理分录，支持借贷平衡检查、
未映射科目/跨期入账检查、模拟关账、正式关账、重开、冲销更正，以及可下钻的试算平衡表。

> **全部数据均为虚构账簿数据**（虚构主体：星辉科技有限公司），数据只保存在当前浏览器的
> `localStorage` 中，不联网、不上传、无后端。

## 启动方式

无需安装任何依赖（Node 仅用于跑测试/本地静态服务）：

```bash
# 方式一：直接用浏览器打开 index.html
# 方式二：启动本地静态服务（推荐，避免个别浏览器的 file:// 限制）
npm run serve          # 然后访问 http://localhost:8080
```

## 功能与操作指南

### 1. 分录与凭证
- 分录按**入账账期、凭证账期、科目、来源凭证号、类型、关键字**筛选；跨期入账的行会标“跨期”徽章。
- 点击任一分录行查看完整凭证（借贷合计、平衡状态、更正链条）。
- “＋ 录入凭证”支持手工多借多贷，实时显示借贷差额；入账账期可与凭证账期不同（即跨期入账）。
- “导入凭证 / 载入错误样本”：粘贴 JSON 数组批量导入，逐条返回成功/拒绝结果。
  - **重复凭证号 → 拒绝，不重复入账**；
  - 借贷不平、未映射科目、凭证缺行（少于两行）、空行、同填借贷 → 拒绝并列出原因，坏凭证完全不入库。

### 2. 账期关账
- 每个账期卡片显示状态（开放 / 模拟关账 / 已关账）、凭证数与借贷合计。
- “检查”输出两类结果：
  - **阻断原因（blocker）**：借贷不平、未映射科目、凭证缺行/空行 —— 存在时**阻止关账**并逐条列出；
  - **警告（warning）**：跨期入账等 —— 不阻断关账。
- **模拟关账**：期间禁止录入凭证，可随时“取消模拟”恢复开放。
- **正式关账**：校验通过后方可执行，关账后该账期原凭证/分录**不可直接修改或删除**。
- **重开**：仅允许重开最后一个正式关账的账期；重开后原凭证仍保持锁定（`everClosed` 标记），
  更正只能走冲销流程。重开后可再次正式关账。

### 3. 试算平衡表
- 三栏六列：期初余额 / 本期发生额 / 期末余额，各栏自动标注借贷是否平衡。
- 期初余额自动汇总该账期之前的全部分录（已关账账期数据带入后续期间）。
- **下钻**：点击科目行查看组成该科目本期发生额的全部分录；点击类别行查看该科目大类全部分录；
  下钻弹窗内再点分录可打开来源凭证。

### 4. 冲销与跨期更正
- 已关账凭证在本页列出，点击“冲销”选择当前开放账期，系统生成 **RV- 前缀、借贷方向相反**的冲销凭证，
  原凭证保持不变，并可紧接着录入更正凭证（新分录），三者形成“原始 → 冲销 → 更正”链条。
- **跨期更正影响**：当冲销账期与原凭证账期不同时，按科目同时展示
  “原账期影响 / 当前账期影响（冲销+更正）/ 两期净额（=更正后结果）”。
- 冲销幂等：一张原始凭证只能冲销一次。

### 数据管理（顶栏）
- **导出数据(JSON)**：下载完整账簿快照；**导入数据文件**：恢复快照。
- **重置为演示数据**：清空 localStorage 并恢复内置虚构账簿。

## 内置演示数据与建议体验路径

演示账簿含 2026-08（已关账）、2026-09、2026-10 三个账期，其中 `PZ-202609-007` 是
9 月凭证 10 月补录的**跨期入账**样本。建议路径：

1. 打开“账期关账” → 对 2026-09 点“检查”（0 阻断）→ “模拟关账”，再到分录页尝试录入凭证，会被阻止；
2. “取消模拟”→“正式关账”；
3. 在“分录与凭证”页打开一张 9 月凭证，确认删除被拒；
4. 回关账页“重开”9 月 → 到“冲销与跨期更正”页对 `PZ-202609-006`（折旧 1,000 元）
   冲销到 2026-10，再录入 800 元的更正分录；
5. 在本页查看跨期影响表（两期净额应为 800），再把 9 月**再次关账**；
6. 打开“试算平衡表”，选 2026-10，点 `6602 管理费用` 下钻，能看到工资 + 冲销 + 更正三条来源；
7. 在“分录与凭证 → 导入凭证”里点“载入错误样本”，观察重复/不平/未映射/缺行四种拒绝原因。

## 架构

```
index.html            页面结构（四个页签 + 四个弹窗）
css/styles.css        样式
js/core.js            账房核心（无 DOM 依赖，UMD，可在 Node 直接 require）
js/seed.js            虚构科目表、种子凭证、坏凭证样本（UMD）
js/app.js             UI 层：localStorage 持久化、渲染与交互
tests/core.test.js    核心规则单元测试（node:test，18 个）
tests/e2e-workflow.js 关账→重开→跨期冲销更正→再关账 全生命周期模拟
tests/dom-smoke.js    轻量 DOM 桩下的 UI 初始化/渲染/交互冒烟测试
```

关键设计：

- **金额一律以“分”整数存储**（`toCents/fmtYuan`），杜绝浮点误差；
- 录入与关账两道校验：`postVoucher` 保证入库凭证合法，`validatePeriod` 负责关账前
  对存量数据（含科目映射事后被删等“变脏”情形）再检；
- 账期状态机：`open → simulated ⇄ open → closed → open(重开，everClosed 保留) → closed`；
- 冲销与原记录通过 `reversesVoucherId / reversalOf / correctsVoucherId / correctionOf` 互相引用，
  原记录在任何状态下都不被改写。
